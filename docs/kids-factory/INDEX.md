# Kids Content Factory Documentation Index

Welcome to the **Kids Content Factory** specification and operations index for zMovie.

Kids Content Factory provides an autonomous, offline-capable children's educational video production pipeline with strict COPPA compliance, deterministic safety verification, and full REST API integration (`/api/v2/kids/*`).
