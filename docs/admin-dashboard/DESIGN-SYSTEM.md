# zMovie Admin Dashboard Design System

Inspired by AdminLTE 3/4 design principles:
- **Colors**: Dark charcoal sidebar (`#343a40`), light content background (`#f4f6f9`), primary blue (`#007bff`), success green (`#28a745`), warning yellow (`#ffc107`), danger red (`#dc3545`).
- **Typography**: Inter / system sans-serif stack.
- **Cards**: Clean white cards with subtle border (`#dee2e6`) and clean header border.
- **Spacing**: Consistent 4px/8px grid.
