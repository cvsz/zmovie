# zMovie Admin Dashboard Requirements

## 1. Overview
The zMovie Admin Dashboard provides unified operational visibility and control over all zMovie subsystems, including production studio, project management, render queue, worker operations, AI providers, media QC, exports, publishing center, ZEAZVERSE, Kids Content Factory, cinema, commerce, analytics, and system health.

## 2. Functional Requirements
- **FR-1**: Display live executive KPIs sourced from verified backend APIs.
- **FR-2**: Provide AdminLTE-inspired responsive sidebar navigation with collapsible state and active route indicators.
- **FR-3**: Integrate existing zMovie production studio, product video studio, and worker monitoring into unified card layouts.
- **FR-4**: Enforce secure session authentication and role-based access control (RBAC).
- **FR-5**: Provide real-time operational status monitoring and render job controls.

## 3. Non-Functional Requirements
- **NFR-1**: High performance and low latency UI rendering.
- **NFR-2**: Full accessibility compliance (WCAG 2.1 AA standards).
- **NFR-3**: Strict adherence to security headers and data privacy boundaries.
